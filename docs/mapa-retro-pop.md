## Orientação cromática vigente — 02/10/2026

A paleta é uma base visual flexível. Cores naturais são permitidas quando harmonizarem com o conjunto, especialmente em árvores, vegetação, grama, chão e materiais. Esta orientação substitui as antigas proibições de cores extras. Os prompts abaixo foram atualizados para refletir essa regra.
