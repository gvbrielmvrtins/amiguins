# XerifINs

Gabriel recebeu a estrela na camisa azul em `public/images/characters/gabriel-martins-v02.png`. Edição via imagegen integrado usando o sprite original: adicionar apenas uma pequena estrela dourada de cinco pontas no peito esquerdo, acima da pipoca, preservando rosto, cabelos, barba, pose, roupas, pipoca, proporções e transparência. A arte anterior foi preservada.
